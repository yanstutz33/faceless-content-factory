# Starter visual pack

These three original scenes were generated for this project with OpenAI's built-in image generation on 2026-08-25. They contain no requested logos, text, characters, or third-party franchise references.

- `lofi-rainy-cafe.jpg`: Japanese-inspired reading cafe, warm paper lamps, books, record player and rainy city window.
- `lofi-cozy-study.jpg`: late-night study room, desk lamp, books, headphones and city window.
- `lofi-cosmic-lounge.jpg`: original orbital observation lounge with books, plants, headphones and a planet view.

The factory selects a scene according to the editorial sound profile whenever the user has not supplied an approved asset. User-owned or licensed library assets still take priority.
